CivicConnect-AI

About

CivicConnect-AI is a project focused on using technology and AI to support citizen engagement and access to civic information.

Technology

- Python
- Google Gemini API
- HTML, CSS and JavaScript (if used in the frontend)

Project Features

- AI-powered chat functionality
- Interactive user interface
- API integration

Installation

1. Clone this repository.
2. Install the required dependencies.
3. Configure your Gemini API key using an environment variable.
4. Run the application.

Security

Never upload API keys, passwords, or ".env" files to GitHub.
